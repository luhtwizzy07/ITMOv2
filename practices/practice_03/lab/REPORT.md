## Модель и конфигурации

Базовая модель — `qwen3.5:4b`: 4.2B параметров по данным Ollama,
формат GGUF, квантизация **Q4_K_M**, размер весов около 3,32 ГБ.
Выбрана небольшая модель из заготовки практики, которую удалось запустить
на ноутбуке с 16 ГБ общей памяти. Другие семейства моделей не сравнивались.

| Конфигурация | ID модели | Контекст | Лимит генерации |
|---|---|---:|---:|
| `Modelfile` | `itmo-local:latest` | 4096 | 512 |
| `Modelfile.agent` | `itmo-agent:latest` | 65536 | 4096 |

Температура обеих конфигураций — 0.2, seed — 42. Первый вариант предназначен
для обычного чата, второй — для агентного чтения репозитория в OpenCode.
Фактический контекст загруженной агентной модели, полученный из `/api/ps`,
составил 65536 токенов. Ollama сообщила около 5,51 ГБ памяти для загруженной
модели; это не измерение пикового потребления всего компьютера.

В `demo/opencode.json` основной и вспомогательной моделью указана
`ollama/itmo-agent`. Агент по умолчанию — `local-guide`, разрешён только
провайдер Ollama. Настроены контекст 65536, выход 4096 токенов,
максимум 8 агентных шагов и `reasoningEffort=none`.

Агент может читать четыре файла учебного сервиса и выполнять поиск.
Изменение файлов, команды, сетевые инструменты и доступ за пределы
рабочей папки запрещены. Системный промпт требует подтверждать выводы
исходниками, указывать строки, проверять предпосылку вопроса и признавать
отсутствие информации. Облачный API-ключ для локальной генерации не нужен.

## Проверка пяти вопросов

Вопросы из `QUESTIONS.md` задавались локальной модели через OpenCode
по одному в пяти новых сессиях. В тестовую папку передавались только
`README.md`, `Makefile`, `service.py`, `test_service.py` из `demo/`
и настройки агента. Эталонные ответы, отчёт и предыдущие ответы
в контекст проверяемой модели не передавались.

Все пять запусков дали непустой ответ и завершились с кодом 0.
Входные файлы после запусков остались неизменными.
Исходные ответы сохранены в `results/q1.md` — `results/q5.md`.
Абсолютные пути внутри ответов относятся к временным тестовым папкам;
одноимённые исходники находятся в `demo/`.

| № | Эталон по исходникам | Сравнение с ответом модели | Результат | Время, с |

## Проблемы, ограничения и выводы

- OpenCode первоначально выбирал корень проекта вместо тестовой папки.
  Явная рабочая папка через `--dir` и корректный `PWD` устранили эту проблему.
- Один предварительный запуск завершился без текста ответа при коде 0.
  В дальнейших запусках были заданы название сессии через `--title`
  и опция `reasoningEffort=none`. Точная причина пустого ответа не установлена.
- В дополнительном вопросе модель исказила длинный путь к файлу, из-за чего
  чтение было заблокировано. После сокращения пути к временной папке повторный
  запуск правильно объяснил обработку пробелов и дубликатов за 18,940 секунды.
- Вопрос о CI проверял только материалы `demo/`. Общие сведения из README
  курса нельзя использовать как подтверждение CI учебного сервиса.
- Наличие ссылки на правильные строки не гарантирует правильную интерпретацию:
  ответ про перезапуск процесса показывает такую ошибку.
- Контекст 64K расходует память; работа с четырьмя короткими файлами
  не подтверждает качество модели на большом репозитории.
- Низкая температура и фиксированный seed не гарантируют одинаковые ответы
  между версиями инструментов и оборудования. Пять вопросов не являются
  достаточным набором для общего вывода о качестве модели.

## Запуск и демонстрация

Открыть приложение Ollama или оставить `ollama serve` в отдельном терминале.
Из `practices/practice_03/lab` выполнить:

```bash
ollama pull qwen3.5:4b
ollama create itmo-local -f Modelfile
ollama create itmo-agent -f Modelfile.agent
make test
```

Для демонстрации подготовить отдельную папку без отчёта и эталонов:

```bash
practice3_dir=$(mktemp -d /tmp/practice3.XXXXXX)
cp demo/README.md demo/Makefile demo/service.py demo/test_service.py demo/opencode.json demo/repo-system.txt "$practice3_dir/"
cd "$practice3_dir"
opencode --pure --agent local-guide --model ollama/itmo-agent
```

Пример нового вопроса: «Что произойдёт после `subscribe(" Ann ")`
и `subscribe("Ann")`? Как будет выглядеть `subscribers`? Подтверди кодом».
Правильный результат — единственный элемент `Ann`, поскольку имя
обрезается через `strip()`, а множество не создаёт дубликатов.

Для отдельной новой сессии с одним вопросом:

```bash
opencode run --pure --dir "$practice3_dir" --title "Practice 3" --agent local-guide --model ollama/itmo-agent 'Как запустить тесты? Укажи файл-источник.'
```

Остальные вопросы задавать аналогично, без `--continue` и `--session`.
Повторные результаты нужно оценивать заново: они могут отличаться от
сохранённой серии. На защите требуется живая демонстрация локального сетапа.
