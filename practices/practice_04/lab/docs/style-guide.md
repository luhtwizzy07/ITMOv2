# Стиль проекта

1. Публичные функции service.py имеют аннотации типов и короткую docstring.
2. Имена нормализуются strip(), пустые имена вызывают ValueError("empty name").
3. Возвращаемые коллекции не открывают доступ к внутреннему изменяемому состоянию.
4. Тест проверяет наблюдаемое поведение и начинает с чистого состояния.
5. Для малой синхронной задачи достаточно стандартной библиотеки; проверки
   не пропускаются и не ослабляются ради PASS.

Пример проверки публичного контракта:

```python
def test_trim(self):
    self.assertEqual(subscribe(" Ann "), {"subscribed": True})
    self.assertEqual(subscribers, {"Ann"})
```

Для списка нужно также проверить независимость возвращённой коллекции.
Для отписки — повторный вызов, отсутствующее и пустое имя, влияние на список.
